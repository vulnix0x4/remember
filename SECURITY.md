# Security policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities or accidentally exposed private data.

Use GitHub's **Report a vulnerability** flow in the Security tab of this repository. Include the affected component, reproduction steps, impact, and any suggested remediation. You should receive an acknowledgment within seven days.

## Scope

Security reports are especially welcome for authentication, authorization, session handling, URL fetching/SSRF, secret exposure, cross-user data access, export deletion, browser-extension permissions, and iOS Keychain/App Group behavior.

Never include real credentials or another person's private archive in a report. Use synthetic test data.
