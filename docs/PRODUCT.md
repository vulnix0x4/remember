# Remember product thesis

## The job

Remember should not be a prettier bookmark manager or a private bundle of ordinary trackers. Its job is to turn the things a person is drawn to into a useful, evolving understanding of what matters to them—and help them carry that understanding into real life.

The core loop is:

1. **Catch it:** save a source or thought with almost no effort.
2. **Understand it:** reveal the idea, moment, tension, and possible personal meaning.
3. **Connect it:** place it inside the themes, questions, and contradictions already shaping the person.
4. **Carry it forward:** keep a principle, try an experiment, make a decision, or deliberately let it go.
5. **Return at the right moment:** resurface it because it is relevant now, not merely because it is old.
6. **Learn from the response:** the person’s confirmations, rejections, and actions make Remember’s understanding more personal over time.

## Product standard

Every major feature should pass three tests:

- **Distinctive:** it could not be dropped unchanged into a generic task manager or read-it-later app.
- **Consequential:** it changes what the person understands, decides, remembers, or does.
- **Alive:** it becomes more useful as saves, reactions, questions, and outcomes accumulate.

Storing, summarizing, listing, filtering, and chatting are ingredients—not finished product experiences.

## Signature experiences

### Everyday decisions

Jev through OpenRouter should take the small planning decisions off the person's plate. Given their tasks, goals, calendar, preferences, and saved context, it ranks what matters and arranges when to do it. Completed recurring chores return automatically. The person can override a task or pause planning without losing their plan. This extends the memory loop into daily action while keeping the existing app's identity.

### Carry it forward

A saved source should offer a meaningful next relationship with the idea: keep it as a principle, try it as a small real-world experiment, connect it to a current direction, or decide it no longer belongs. Experiments enter Plan with their source and intent attached, so the jump from inspiration to action takes one decision instead of manual rewriting.

### Living threads

Remember should form evolving threads around the questions a person repeatedly returns to. A thread combines relevant saves, the strongest agreements and disagreements, what the person has explicitly said, how the view changed, and what remains unresolved. It is a living line of thought, not a folder or generated summary.

Memory check-ins are turning points inside a thread, not disposable feedback. A thread should show where the person reaffirmed an idea, saw it differently, left it open, or let it go, then shape the next question around that current state. The value of responding once must be visible the next time the person returns.

### A personal compass

Kept principles, confirmed relevance, recurring tensions, and completed experiments should become a user-controlled compass: what currently feels true, what is being tested, what has changed, and which evidence shaped it. Remember proposes; the person decides.

### Contextual return

Today uses active goals, the current task, the next calendar event, recent Ask questions, memory check-ins, and real experiment outcomes to choose one save that may matter now. It explains the connection, offers one sourced action that can enter Plan, and lets the person say “Not for today” so the next return improves. It is a decision surface, not a feed of old content.

### Memory check-ins

Every meaningful return should close with one small judgment: this still feels true, I see it differently, I am not sure yet, or this no longer belongs. Remember should immediately explain what it learned, carry that response into the personal compass, and use it to make future returns more relevant. The goal is not engagement for its own sake; it is a memory system that grows alongside the person using it.

### Work with my memory

Ask should create useful outcomes from the library, not only paragraphs. It should be able to build a position map, compare competing ideas, recover a half-remembered source, challenge an assumption, assemble a plan, or turn a cluster of saves into a living thread. The result should remain traceable to the person’s own material.

## Product sequence

1. Close the inspiration-to-action loop with **Carry it forward**.
2. Turn Patterns into **Living threads** rather than aggregate counts.
3. Deepen Today’s contextual return surface as current life and prior responses accumulate.
4. Make Ask produce interactive outcomes that can become threads, principles, or experiments.
5. Keep Life modules only where they improve those signature experiences; ordinary tracking is secondary.
